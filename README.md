Um repositório simples e organizado, dedicado a guardar meus exercícios, scripts e anotações das aulas de Banco de Dados do SENAI.

## 🚀 O que tem por aqui?
* Scripts de criação e normalização de tabelas.
* Automações no banco com `TRIGGERS` e funções.
* Criação de `VIEWS` para visualização de dados estruturados.
* Migração de dados de planilhas CSV para o banco.

## 🛠️ Tecnologias e Ambiente
* **Linguagem:** SQL
* **SGBD:** PostgreSQL
* **Sistema:** Desenvolvido e testado rodando liso no Linux (EndeavourOS) 🐧
